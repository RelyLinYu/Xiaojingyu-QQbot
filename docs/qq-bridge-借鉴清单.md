# qq-bridge 借鉴清单（2026-10-23）

> 对象：[Derpyu520/qq-bridge](https://github.com/Derpyu520/qq-bridge)（★1800+，OneBot v11 ↔ DeepSeek Harness）。
> 结论先说：**它的整体形态是"每个 QQ 会话 = 一个 DSH agent 会话，模型拿工具自己收发"，我们是"规则管线 + 单次生成"**。
> 整体照搬等于重写；但里面有一批**与架构无关的机制**可以直接吸收，本文按性价比排序。

## 一、它比我们强的 10 个点

| # | 机制 | 它怎么做的（代码位置） | 我们的现状 | 判断 |
|---|---|---|---|---|
| 1 | **回复审计** | 回复里出现本机路径（`C:\`、`/home/`）或凭据特征（token/password/secret/api key）→ **整条不发**，改回"被安全策略拦截"（RULES.md §6） | 只过滤了"不确定的链接"和知识闸，**没有路径/凭据拦截** | ✅ 值得抄（成本极低） |
| 2 | **会话归属只认 id** | OneBot 的 `group_id`/`user_id` 就是会话 key，昵称只用于显示（`sender.card \|\| nickname`） | 今天已改成"日志带稳定 id"（`42041d5`） | ✅ 已抄 |
| 3 | **黑话候选 → 确认** | 出现次数到 2/4/8 阈值才联网研究；`candidate → confirmed/rejected`，**默认不自动转正**，控制台人工确认 | 已做自动采集（用户要求"让 bot 自己加"），**自动转正** | ⚠️ 半抄：候选池 + 阈值已有，"待确认"态可选（用户要自动，先不做） |
| 4 | **抢话保护** | 收到新消息后至少再等 10 秒才开口（`minQuietAfterNewMs`），批量窗口 8 秒合并判断 | 没有：每条消息独立判断，冷却只防刷屏 | ✅ 值得抄（只需改发送节流） |
| 5 | **分条发送** | 模型用**空格**表示分条，最多 8 条，条间 1~3 秒，10% 概率拉长到 2.5~5 秒 | 一次只发一条 | ⏳ 可选（会改变语气节奏，需你点头） |
| 6 | **两层提示词** | 行为协议（工具/分条/安全）与人设**分开**：`仿真提示词 → 人格提示词 → 本轮消息`；人设卡不许写工具用法 | 人设 + 协议混在一个 system 里 | ⏳ 有长期价值，但改动大（要拆 prompt 结构） |
| 7 | **安全边界** | QQ 会话 agent **没有本地工具**、发送强制白名单、人格只能控制台改、群友无法改角色 | 我们本来就是规则管线，天然无本地工具；但**没有"发送白名单"概念**（只有图库测试群） | ⏳ 我们暴露面更小，暂不需要 |
| 8 | **token 账本** | 按轮次/群/好友下钻，高峰/空闲双价，节假日表 | 有 `budget`/`usage`，按天/按群粗粒度 | ⏳ 现有够用 |
| 9 | **管理命令硬执行** | `/role`、`/silent`、`/reset` 由桥接直接执行，不经模型 | 我们的 `#` 指令也是硬执行 | ✅ 已一致 |
| 10 | **测试/文档纪律** | `test-audit` 统一入口 + 一份"文档是否仍有效"索引 + 目录地图 | 我们有 `test-brain` + `regress.sh` | ✅ 已一致 |

## 二、明确**不抄**的

- **社交状态机（观望/活跃/冷场/主动开话题）**：和"省钱 + 安静"直接冲突，一天几十次主动开口，费用不可控。
- **每群一个 DSH 会话**：架构代差太大，等于把整个 bot 重写成 agent。
- **语音/表情包收藏/贴吧浏览**：不是我们的需求面。

## 三、落地顺序

- **P0（本次已做）**：
  1. 回复审计（路径/凭据拦截）；
  2. 会话归属稳定 id（上一轮已完成）。
- **P1（建议下一轮）**：
  3. 抢话保护：新消息到达后 5~10 秒内不开口（只影响"正准备发"的那一轮）；
  4. 黑话候选"待确认"态（若你以后想人工把关）。
- **P2（可选，改动大）**：
  5. 分条发送（默认关，可面板开）；
  6. 提示词两层拆分（协议层 / 人格层）。

## 四、P0-1 实现说明（回复审计）

`brain.sanitizeReply()` 在原有"未登记链接 → 提示别点"之后，新增一条硬拦截：

```
本机路径：C:\ / /opt/ / /home/ / /root/
凭据特征：sk-xxxxxxxx / api_key= / password= / secret= / token=<8位以上>
```

命中就**整条替换**成「这条我不方便发。」并打 `[reply-audit]` 日志；宁可少说一句，也不把服务器路径或密钥发到群里。
