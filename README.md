# 🐋 蓝色大肥鱼 · QQ 群机器人

> 一个跑在云服务器上的 QQ 群聊 AI 机器人。**自研，零第三方依赖** —— 只需要 Node 22+。
>
> 不是框架、不是现成软件，是手写的完整链路：**鉴权 → 长连接 → 事件分发 → 分层决策 → 模型调用 → 限流 → 发送 → 容错**。

---

## 它是什么

在 QQ 群里像一个**有性格的群成员**那样聊天，而不是一个"问答接口"。

| 特点 | 说明 |
|---|---|
| **拟人** | 甜系傲娇的「鲸鱼娘」人设，会吐槽、会得意、会用括号写动作 |
| **有分寸** | 不该说话时**真的沉默** —— 别人互相 @、机器人不抢答 |
| **能干活** | 用暗号 `ovo` 可切换成「精准回答」模式，给步骤、给代码 |
| **记得住** | 最近 30 条 / 10 分钟内的上下文；冷场后自动忘记旧话题 |
| **花钱有上限** | 每天 ¥3、总计 ¥10，超了自己在群里喊"没钱了" |
| **可观测** | 自带手机可看的日志网页（额度 / 最近消息 / 实时日志） |

## 功能

### 对话与人格

- **示例对话驱动语气** —— 把示例作为**真实的多轮消息**传给模型（不是写在提示词里的文本），
  模型看到的是"自己以前这么说过话"，模仿效果远强于规则说明
- **提示词可切换** —— `lean`（248 字）/ `full`（744 字）两套都在代码里，改一个词即可回退
- **反重复机制** —— 把它最近说过的 5 句话回灌进提示词，要求"换个说法"，
  避免反复被挑衅时永远回同一句
- **多行分段发送** —— 超 40 字按句末标点切分，段间 0.8~1.8 秒**随机**间隔（固定间隔像机器）
- **半角括号写动作** —— `(尾鳍啪地甩过来)`，一条消息最多一个，只在情绪明显时用

### ⭐ 助手模式（暗号 `ovo`）

```
群友: ovo 帮我解释一下什么是递归        → 精准回答（给定义 + 代码 + 要点）
群友: ovo 我服务器 nginx 502 了怎么排查  → 给 6 步排查流程，每步带命令
群友: ovo                               → 只有暗号，等于没说话
群友: @蓝色大肥鱼 ovo 解释下量子纠缠     → 先剥 @ 再认暗号，也生效
```

**助手模式下的行为差异**：

| 项 | 普通模式 | 助手模式 |
|---|---|---|
| 人设语气 | ✅ | ✅ **保留**（可以"又是我……行吧"，但活要干完） |
| 不分段 | — | ✅ 不拆答案（但代码块/编号列表保持完整） |
| 反重复 | ✅ | ❌ 关闭（为换说法改写会损害准确性） |
| 冷却/抽样/长度限制 | ✅ | ❌ 全部绕过（明确要答案，不该被省钱逻辑拦） |
| **日额度** | ✅ | ✅ **仍然生效**（钱包底线） |

### 什么时候会说话

| 场景 | 行为 |
|---|---|
| **@它 + 有内容** | ✅ 一定回 |
| **@它 + 没写字** | ✅ 回一句「咋了」这类 |
| **@别人** | ❌ **不抢答** |
| 没 @人 + 提到关键词（大肥鱼/蓝鲸…） | ⚠️ **50% 概率**，且**引用原消息** |
| 没 @人 + 没关键词 | ❌ 完全不回 |
| **私聊** | ✅ 一定回 |

**还有五道"刹车"**：深夜静默（2~7 点）· 同人 60 秒冷却 · 同群 3 分钟最多 2 次 ·
太短不理 · 每天最多 300 次调用。

## 架构

```
                    QQ 开放平台
                         │  WebSocket（官方 API v2）
                         ▼
   ┌──────────────────────────────────────────────┐
   │  gateway.js    长连接 · 心跳 · 断线指数退避重连  │
   │  auth.js       AccessToken 获取与缓存          │
   └──────────────────────┬───────────────────────┘
                          ▼
   ┌──────────────────────────────────────────────┐
   │  index.js      事件分发 · 去重 · 预算拦截 · 发送 │
   └──────────────────────┬───────────────────────┘
                          ▼
   ┌──────────────────────────────────────────────┐
   │  brain.js      ┌─ L0 硬规则（纯正则，不花钱）  │
   │                ├─ L1 判断（小模型：该不该接话）│
   │                └─ L2 生成（人设 + 上下文 + 分段）│
   └──────────────────────┬───────────────────────┘
              ┌───────────┴───────────┐
              ▼                       ▼
   ┌──────────────────┐   ┌──────────────────────┐
   │  budget.js       │   │  qqapi.js            │
   │  双预算 + 按量计价 │   │  发送 · 错误码翻译 · 重试 │
   └──────────────────┘   └──────────────────────┘
                          ▼
   ┌──────────────────────────────────────────────┐
   │  tools/logweb.js   日志网页（手机可看）        │
   └──────────────────────────────────────────────┘
```

**设计原则**：**能不用模型解决的，就不用模型。**
L0 全是纯正则（长度、冷却、@ 判定、静默时段），**零成本**；
只有真正需要语义判断的才交给 L1；L2 只负责"怎么说"。

## 快速开始

### 环境

- **Node 22+**（需要全局 `WebSocket`）
- 一台能联网的服务器（本项目在 2核2G / Ubuntu 24.04 上跑）
- 一个 [QQ 机器人](https://q.qq.com) 应用（拿 AppID / AppSecret）
- 一个模型 API Key（默认 [DeepSeek](https://platform.deepseek.com)，OpenAI 兼容格式）

### 部署

**一键脚本**（Ubuntu，含 Node 安装 + systemd 配置）：

```bash
sudo bash deploy.sh
```

**手动配置**：

```bash
cp .env.example .env
# 填入 AppID / AppSecret / API Key / 主人 openid / 日志页密码
chmod 600 .env
node test-brain.js | tail -2      # 应显示：153 通过 / 0 失败
sudo systemctl restart xiaolanjing
```

### ⚠️ 两个必踩的坑

| 坑 | 症状 | 正解 |
|---|---|---|
| **主人标识填 QQ 号** | 主人规则**静默失效**、无任何报错 | 必须填 `member_openid`（QQ 不提供 QQ 号） |
| **Windows CRLF 污染 `.env`** | 配置"明明写了"却读成空 | 用 `printf \| sudo tee`，别用 nano 粘贴 |

**153 项自测**，覆盖：

## 已知限制

| 限制 | 原因 |
|---|---|
| **不能看图** | 未接入视觉模型 |
| **群里未 @ 时不接陌生话题** | 刻意设计 —— 群聊里最招人烦的是机器人抢答 |
| **改人设需重启** | 配置每次启动读取 |
| **上下文是内存态，重启清空** | 重启后重新观察，合理 |
| **不可真 @ 别人** | QQ 不暴露用户 openid，做不到 |
| **会话历史有限** | 30 条 / 10 分钟；更长的信息靠提示词承载 |
