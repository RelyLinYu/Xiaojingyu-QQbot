## 概念：一口深呼吸潜下去

**一条聊天窗口，一个镜头，不切。**

这支片子只有一个世界（那扇聊天窗口）和一架镜头。所有"切场景"都是**同一个东西长大成下一个场景**：
开场最后那个小圆点撑开成窗口；消息是从「发送键」和「头像」里长出来的；链接的封面从卡片里
长到满屏、又收回去；最后整扇窗口被吸回头像那一点，变成那只鲸鱼，那只鲸鱼变成 GitHub 地址。

**手是全程可见的** —— 一条连续的指针轨迹，字是它敲的，发送是它按的，人设卡片是它点的。
画面上出现的每件事都有可见的成因。

## 分镜（32 秒）

| 秒 | 拍 | 动的是什么 | 谁carry过去 |
|---|---|---|---|
| 0.0–1.1 | 开场：「群里有 一条 鱼。」 | 三个词各自落定 | 最后一个字的那个点 |
| 1.1–1.7 | 那一点撑开成聊天窗口 | 窗口矩形 + 内容一起缩放 | 那一点 → 这扇窗 |
| 1.7–3.3 | 手进场，在输入框里敲出第一句 | 手、光标、输入框 | 输入框 |
| 3.3–4.0 | **接梗**：`大肥鱼是什么牌子的鱼？` → `(甩了甩尾巴) 深海的，很贵那种` | 气泡从发送键/头像弹出 | 气泡 |
| 4.0–5.3 | 静一下（1.1 s） | 只有极慢的漂移 | — |
| 5.3–6.7 | **踩雷**：`你是不是又胖了` → `(尾鳍啪地甩过来) ……你再说一遍？` | 镜头发抖 + 红光 + 气泡被打歪 | 那一下"挨打" |
| 6.7–8.4 | **情绪**：`你好厉害啊` → `(尾巴得意地摆了摆) 嗯，我知道` | 两拍快切 | 气泡 |
| 8.4–13.2 | **视频解析**：手贴抖音链接 → 卡片从头像长出来 | 手、卡片 | 卡片的封面 |
| 13.2–14.3 | 封面**长到满屏**（集装箱变成下一场） | 那个矩形 | 封面 → 满屏 |
| 14.3–16.6 | 里面：四个平台 + 「信息卡片：0 次模型调用」 | 四个chip依次落 | 满屏画面 |
| 16.6–18.0 | 收回来 | 矩形反着走 | 同一扇窗 |
| 18.0–21.3 | **人设切换**：抽屉滑入，手点第二张卡，**同一句话**的回答滚上去换掉 | 抽屉、那一条回答（滚动换字） | 那句话 |
| 21.6–24.1 | **能力行**：五条一句一条滚上来 | 列表连续上滚 | 那个列表 |
| 24.1–25.6 | 停一下：「人设 = 提示词 + 示范」（作者原话） | — | — |
| 25.8–26.7 | **整扇窗口收回头像那一点** | 世界本身 | 窗口 → 鲸鱼 |
| 26.7–32.0 | 鲸鱼落到画面上，GitHub 地址打出来，四个数字落定 | 字 | — |

**节奏**：镜头长度从 0.5 s 到 2.5 s 不等（自动验收里 CV 0.49，要求 ≥0.25）；全片 **38% 的帧是静止的**，
最长一段安静 4.1 s。

## 相比第一版改了什么（对着你提的四条）

| 你提的 | 这版怎么做 |
|---|---|
| **没有背景 BGM** | 加了一整条 BGM：低音区 Am–F–C–G 四和弦的 pad，84 BPM，每个和弦留 25% 空隙。**是合成的，不是下载的素材**，所以没有授权问题 |
| **节奏太慢、有些没必要详细演示** | 78 秒 → **32 秒**。「已读回执 / 正在处理 7.7MB」那两屏压成**一行 0.4 秒的闪字**；六个特色卡改成**五条一句话滚过去** |
| **消息更新时不流畅（加载点 → 一下跳成结果）** | **加载点整个删了**。打字发生在输入框里（看得见手在敲），消息从**发送键**里长出来、带落地压扁；机器人的回复从**头像**长出来。没有"先占位再替换" |
| **分镜之间没有过渡，直接跳** | 全片**一个镜头不切**。每个场景边界都是上一件东西长大/收缩成下一件（点→窗口→卡片→满屏→窗口→鲸鱼→地址） |

另外：`不要 AI 配音`、`不提加 QQ / 群号 / 扫码` 两条照旧守着；GitHub 链接和特色照旧在片子里。

## 怎么改 / 怎么重出

```bash
# 改画面：onetake/comp.html 里搜「时间轴」和「世界坐标」，台词与节拍都在那两个对象里
#   TYPING / MSGS / ROWS_TXT / HAND（手走过的点）/ CAMKEYS（镜头关键帧）

# 抽帧看效果（3 列一张图，改一次看一眼）
python onetake/sheet.py 0.9,3.4,6.75,14.4,20.1,26.3      # 需要 ffmpeg

# 只看画面，不渲染
python scripts/stills.py onetake/comp.html --times 3.4,6.75,14.4,20.1 --out sheet.png

# 改声音 → 重出音轨
python onetake/score.py onetake/sfx.wav

# 重新渲染成片（约 4 分钟 / 8 进程；1920×1080 30fps + 180° 真快门动态模糊）
python scripts/render.py onetake/comp.html --out promo/bigfish-promo.mp4 --sfx onetake/sfx.wav

# 自动验收（节奏 / 静帧 / 声音 / carry / 曲线）
python scripts/verify_promo.py promo/bigfish-promo.mp4 --comp onetake/comp.html --shots 0,1.1,1.7,3.3,6.1,6.7,8.4,13.2,14.3,16.6,18.0,19.95,21.6,24.1,25.8,26.7,28.2,32.0
```

> `scripts/*.py` 指 onetake 技能自带的脚本，在 `C:\Users\Baiks\.dsh\skills\onetake\scripts\`，
> Python 用 `C:\Users\Baiks\.dsh\onetake-venv\Scripts\python.exe`。

### 换成真实素材（建议做）

片子里抖音的**封面和视频画面是明示的占位**（「封面（示例占位）」「视频画面（示例占位）」），
因为仓库里不能放来源不明的素材。换成你自己的群截图最好（群名昵称打码）：

- 封面：`comp.html` 里 `.cardmsg .cov` 那个 div，把 `.tag` 换成 `<img src="./cover.png" style="width:100%;height:100%;object-fit:cover">`
- 视频画面：`drawCover()` 里那几笔 canvas 换成 `c.drawImage(封面图, 0, 0, 1920, 1080)`
- 第二个人设「冷静 · 直给」是**示意**，换成你真实的预设名。
